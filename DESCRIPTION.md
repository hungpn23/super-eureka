# Mô tả tổng quan hệ thống Vocabify

Vocabify là một ứng dụng web hỗ trợ học từ vựng được thiết kế và phát triển theo kiến trúc client-server, bao gồm hai thành phần chính: frontend xây dựng trên nền tảng Nuxt 4 (Vue 3) và backend xây dựng trên nền tảng NestJS (Node.js), cả hai đều sử dụng TypeScript để đảm bảo tính nhất quán về kiểu dữ liệu xuyên suốt hệ thống. Về phía backend, ứng dụng sử dụng PostgreSQL làm cơ sở dữ liệu quan hệ thông qua MikroORM để quản lý các thực thể như User, Deck, Card, Notification và UserStatistic; Redis đóng vai trò kép vừa làm bộ nhớ đệm (caching) với thư viện cache-manager vừa làm hàng đợi tin nhắn (message queue) thông qua BullMQ để xử lý các tác vụ nền như cập nhật thống kê học tập và xử lý ảnh đại diện người dùng qua ImageKit; đồng thời tích hợp Qdrant làm cơ sở dữ liệu vector kết hợp với mô hình embedding đa ngôn ngữ của Cohere (thông qua LangChain) để cung cấp tính năng gợi ý từ vựng dựa trên tìm kiếm tương đồng ngữ nghĩa (semantic similarity search). Hệ thống xác thực được triển khai toàn diện với ba phương thức đăng nhập — xác thực cục bộ (username/password kết hợp xác minh email bằng OTP), Google OAuth 2.0 theo Authorization Code Flow, và Magic Link (đăng nhập không cần mật khẩu qua email) — cùng với cơ chế quản lý phiên làm việc sử dụng cặp JWT token (access token 30 phút, refresh token 14 ngày) được lưu trữ trên Redis với chiến lược Token Rotation để hỗ trợ đăng nhập đồng thời trên nhiều thiết bị, bổ sung thêm luồng đặt lại mật khẩu qua OTP và kiểm soát truy cập dựa trên vai trò (Role-Based Access Control). Về phía frontend, ứng dụng áp dụng kiến trúc phân chia theo tính năng (feature-based architecture) với các module độc lập gồm auth, card, create-deck, deck, study và user; sử dụng bộ thành phần Nuxt UI v4 với hỗ trợ giao diện sáng/tối, quản lý trạng thái tập trung bằng Pinia với cơ chế persist, xác thực dữ liệu đầu vào bằng Valibot, và một server proxy catch-all để chuyển tiếp toàn bộ yêu cầu API đến backend. Ứng dụng cung cấp ba chế độ học tập chính: Flashcard cho phép lật thẻ ôn tập với theo dõi biết/không biết và tự động lưu tiến trình, Learn mode hỗ trợ câu hỏi trắc nghiệm và tự luận theo hai chiều (thuật ngữ ↔ định nghĩa) với hệ thống gợi ý và hiển thị khác biệt câu trả lời, và Test mode phục vụ kiểm tra đánh giá với số lượng và dạng câu hỏi tùy chỉnh. Cốt lõi của quá trình học tập là thuật toán lặp lại ngắt quãng (spaced repetition), trong đó mỗi thẻ từ vựng được quản lý thông qua ba thuộc tính: chuỗi trả lời đúng liên tiếp (streak), ngày ôn tập tiếp theo (reviewDate) và trạng thái tiến trình (new → learning → known), được cập nhật tự động tại tầng entity thông qua lifecycle hooks của ORM. Ngoài ra, hệ thống còn tích hợp thông báo thời gian thực qua WebSocket (Socket.IO) khi có người dùng khác sao chép bộ thẻ, gửi email giao dịch qua Resend với template React Email được xử lý bất đồng bộ qua hàng đợi BullMQ, và cung cấp tài liệu API tự động thông qua Swagger UI — tạo thành một hệ thống học từ vựng hoàn chỉnh với đầy đủ các khía cạnh kỹ thuật từ xác thực, quản lý dữ liệu, xử lý bất đồng bộ, giao tiếp thời gian thực đến trí tuệ nhân tạo.
